# Power BI Basics

This section covers the fundamentals of Power BI for beginners.

---

## 🔹 1. What is Power BI?
Power BI is a data visualization and business intelligence tool used to create dashboards and reports.

---

## 🔹 2. Interface Overview
- Report View → Create charts
- Data View → See raw data
- Model View → Manage relationships

---

## 🔹 3. Importing Data
- Excel / CSV
- SQL Database
- APIs

---

## 🔹 4. Basic Visuals
- Bar Chart → Compare categories
- Line Chart → Trends over time
- Pie Chart → Distribution (use carefully)
