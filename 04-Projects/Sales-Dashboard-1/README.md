# 📊 Sales Dashboard (Power BI)

## 📌 Overview

This project is my first Power BI dashboard created using a sales dataset.

following this tutorial 👉 [click here](https://youtu.be/6cV3OwFrOkk?si=ET86A2Frs97iAzyU)

The goal was to understand how to:
- Import data
- Create relationships
- Build visualizations
- Extract basic insights

---

## 📂 Dataset

- Orders data
- Details data

The dataset contains information about:
- Sales
- Profit
- Categories
- Regions

---

## 🛠 Tools Used

- Microsoft Power BI
- Excel (CSV files)

---

## 📊 Dashboard Features

- Sales by Region (Bar Chart)
- Profit Trends (Line Chart)
- Category-wise Sales (Pie Chart)
- Key Metrics (Cards)

---

## 🧠 What I Learned

- Connecting multiple datasets
- Creating basic charts
- Using filters and slicers
- Understanding Power BI interface

---

## ⚠️ Challenges Faced

- Tutorial used older Power BI version
- Some UI options were different
- Had to explore features manually

---

## 📊 Key Insights

- Certain regions perform better than others
- Some categories generate more profit
- Sales trends vary over time
